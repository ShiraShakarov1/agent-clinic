# Mission

## Purpose

Agent Clinic is a demonstration application built using Spec-Driven Development (SDD) methodology. The purpose is to showcase how specifications serve as the single source of truth throughout the development lifecycle.

## Core Mission

To build a functional, well-architected application that demonstrates:
- Specification-first development workflow
- Type-safe TypeScript with strict mode
- Clean separation of concerns
- Testable code structure
- Iterative feature development with validation

## Application Domain

Agent Clinic is a simple web application that manages "Agents" and "Ailments" - a playful concept where agents (AI assistants, bots, or virtual characters) can have ailments (issues, problems, or conditions) that need attention.

## Values

1. **Specifications are the source of truth** - All implementation decisions trace back to specs
2. **Type safety** - TypeScript strict mode enforced
3. **Clean code** - Readable, maintainable, well-structured code
4. **Testability** - Every feature has corresponding tests
5. **Iterative improvement** - Build, validate, improve cycle
